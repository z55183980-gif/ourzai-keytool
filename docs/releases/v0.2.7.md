本次仅发布 **ourzai / zAI Key Manager**，不包含其他独立项目或网站部署。

## 新增

- 接入签名自动更新：检查新版本、下载并校验、安装和重启，支持失败重试及手动下载。
- 最低客户端版本策略生效：升级提示、后端拦截、最近有效策略缓存；远程配置独立托管于本仓库。
- 托盘支持按上次配置启动 Claude / Codex、打开对应密钥选择器、选择最近项目目录。
- 客户端安装与更新指引：官方链接、可复制安装命令、安装后重新检测，以及 CLI 本机版本与最新稳定版本检查。
- 应用更新卡片位于设置页最底部。

## 修复

- 修复配置写入、备份恢复、密钥管理和客户端启动中的上线阻断问题，补充回归测试。
- 桌面版和 CLI 按各自配置范围应用并校验密钥，启动失败时保留恢复路径。
- 处理重复操作、无效项目目录和网络失败，避免把版本检查失败误报为已是最新。

## 下载与升级

- Windows x64：推荐 `zAI-Key-Manager_Windows_x64-setup.exe`；另提供 MSI 和便携版。
- macOS：推荐 DMG；Intel / Apple Silicon 通用版，含 Developer ID 签名及 Apple 公证。
- **v0.2.6 及更早版本需手动下载安装一次 v0.2.7**。本版本开始支持后续自动更新。
- Windows 便携版使用应用内更新时会转为安装版，后续请启动已安装的应用。
- Windows 包尚未配置 Authenticode 代码签名，SmartScreen 可能提示未知发布者；应用内更新包使用独立 Tauri 签名校验。
- `latest.json`、`.sig` 和 `.app.tar.gz` 供自动更新使用。安装包的 SHA-256 见 `SHA256SUMS.txt`。

当前最低版本保持 `0.2.6`，本次不强制拦截已有兼容客户端。密钥库标识与数据目录保持兼容。
