# zAI Key Manager v0.2.12

- 修复：升级到 v0.2.11 后，已经配置过的 Claude 桌面版和 Claude Code 不会自动补上网关上的其他模型，选“沿用当前配置”时模型菜单里仍然只有 Opus 5.5 和 Sonnet 5.5。现在体检会提示“Claude 桌面版的模型菜单缺少网关上的其他 Claude 模型”和“Claude Code 没有打开网关模型发现”，点“修复”即可补上 Fable 5.2 和 Sonnet 4.6。
- 修复：v0.2.11 写入 Claude 桌面版配置后会误报“仍有外部配置或认证覆盖”，导致保存和换模型失败。
- 桌面版修复后需要完全退出（包括托盘图标）再重新打开，新的模型菜单才会出现。

当前最低版本保持 `0.2.6`，v0.2.8 及以后的版本可以在应用内自动更新。
