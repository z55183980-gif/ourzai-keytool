# zAI Key Manager v0.2.11

- Claude Code 的 `/model` 列表现在会显示网关上的全部 Claude 模型：用 zAI 密钥配置时会打开网关模型发现（`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`），除 Opus 5.5、Sonnet 5.5 外，还会出现 Fable 5.2 和 Sonnet 4.6。“切回官方”时这一项会一并移除；其他服务的密钥不受影响。
- Claude 桌面版的模型菜单同样补上 Fable 5.2 和 Sonnet 4.6，你选的默认模型仍排在第一个。以后网关新增模型，可以通过远程配置下发，不必再发新版本。
- 已经配置过的用户，需要在工具里重新应用一次配置；桌面版要完全退出后重新打开才会生效。

当前最低版本保持 `0.2.6`，v0.2.8 及以后的版本可以在应用内自动更新。
