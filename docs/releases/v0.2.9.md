本次仅发布 **ourzai / zAI Key Manager**，不包含其他独立项目或网站部署。

## 新增

- 首次使用引导：欢迎页、本机环境检查（安装、版本、配置和体检进度）、Claude Code / Codex 桌面版与 CLI 的安装和更新，以及通过 zAI 登录或 API Key 接入密钥。已配置好的用户可直接完成。
- 工具页连接指引：未检测到服务时，可选择官方账号、zAI 账号或 API Key；保存配置后的提示带 5 秒撤销。
- 界面语言新增俄语，系统语言为俄语时自动选用；引导页使用轻量语言菜单。
- 写入或还原配置后，若 Claude / Codex 桌面版正在运行，会弹窗确认，并由本工具退出（包括托盘和后台进程）后重新打开，新配置才生效。终端里的 CLI 会话不受影响。
- 用 API 启动 Claude 桌面版时，若桌面版记着 Claude.ai 官方登录，会弹窗确认后切换到第三方推理并重新打开；改动有备份，可撤销。Claude.ai 账号不受影响，之后可在桌面版里切回官方登录。
- 服务列表中未在使用的密钥也能直接更换模型；只有使用中的密钥会立即写入配置。
- 换模型弹窗重新排版，思考深度改为分段选择。
- 窗口默认尺寸改为 480×865，标题栏只保留图标。

## 修复

- 启动已在运行的桌面版时只会激活旧窗口，看起来没有反应，且仍用旧配置；现在会确认后重启。
- 按客户端兼容性审计加固 Claude / Codex 配置写入：Codex 按 CLI 版本选择认证方式，切回官方时只还原本工具接管的字段；Claude 桌面版加密后的密钥只在条目、地址和模型都未变时才认作本工具写入；写入期间文件被改动则中止而不覆盖。
- 客户端下载按官方地址可达性选择一条线路，不再中途切换线路或因低速中断。
- 服务选择改为内联列表，标明启动将使用的服务和配置文件当前在用的服务；可导入本机已有的凭据。

## 下载与升级

- Windows x64：推荐 `zAI-Key-Manager_Windows_x64-setup.exe`；另提供 MSI 和便携版。
- macOS：推荐 DMG；Intel / Apple Silicon 通用版，含 Developer ID 签名及 Apple 公证。
- v0.2.8 可在应用内自动更新；v0.2.6 及更早版本需手动下载安装一次。
- Windows 包尚未配置 Authenticode 代码签名，SmartScreen 可能提示未知发布者；应用内更新包使用独立 Tauri 签名校验。
- `latest.json`、`.sig` 和 `.app.tar.gz` 供自动更新使用。安装包的 SHA-256 见 `SHA256SUMS.txt`。

当前最低版本保持 `0.2.6`，本次不强制拦截已有兼容客户端。密钥库标识与数据目录保持兼容。
